# scripts 目录

存放开发辅助脚本。

## 一键启动脚本（Windows）

| 文件 | 作用 |
| --- | --- |
| `启动后端.bat` | 启动 FastAPI 后端（`http://127.0.0.1:8000`） |
| `启动前端.bat` | 启动前端开发服务器（`http://localhost:5173`），服务就绪后自动打开浏览器 |

用法：**双击**即可，两个脚本各开一个窗口；关闭窗口即停止对应服务。

首次运行时脚本会自动：创建 Python 虚拟环境并安装依赖、从 `.env.example` 复制 `.env`（前端则自动 `npm install`）。
若提示需要填写数据库配置，请修改 `backend/.env` 后重新双击。

注意：

- 前端与后端要**同时运行**才能看到数据。
- 使用 `localhost` 而非 `127.0.0.1` 访问前端：Vite 默认只绑定 `localhost`。
- 不要双击 `frontend/dist/index.html`。该文件是构建产物，需由服务器托管访问，直接双击会白屏。

## 约定

1. 脚本必须是可跨平台使用或明确标注适用平台（Windows `.bat` / `.ps1`，macOS·Linux `.sh`）。
2. 脚本里**不允许写死数据库密码**，需要配置时从 `backend/.env` 读取。
3. 脚本的运行产物（日志、导出文件）不要提交到仓库。
4. Windows 批处理文件内容**保持纯 ASCII**：中文等非 ASCII 字符在默认 GBK 代码页下会被 cmd 错误解析，导致脚本执行失败（文件名可以用中文）。
