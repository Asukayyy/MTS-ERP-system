# 课程参考数据（data/reference）

本目录存放**课程提供的原始参考文件**，是系统验收案例（Case 2 转椅 MTS）的权威数据来源。

## 目录内容

| 文件 | 说明 |
| --- | --- |
| `BOM例子.doc` | 课程《制造管理信息系统专业课程设计案例》，含 5 个案例的产品 BOM。我们采用 **案例2：某办公家具生产企业 —— （1）转椅 BOM** |
| `附录1：主生产计划.xls` | 主生产计划 MPS、成品期初/预计期末库存，以及“各级物料期初库存”说明 |
| `制造管理信息系统专业课设计教学大纲任务书-2026实战工作坊.doc` | 课程设计任务书（教学大纲） |

## 数据提取说明（重要）

1. **转椅 BOM 不是文本表格**。
   `BOM例子.doc` 中的 BOM 全部是**内嵌的 Visio 绘图对象**（`EMBED Visio.Drawing.11`），
   Word 正文里没有物料名称、数量等文字。
   因此“读取原始文件”必须解析 `ObjectPool/_1445321627/EPRINT`（EMF 打印流）才能拿到图形中的文字与坐标，
   再依据连线还原多层级 BOM 结构。

2. **MPS 与库存数据是真实可读的**。
   `附录1：主生产计划.xls` 的 `Sheet1` 为真实数值，已原样记录到 `data/seed/course_chair_case.json`。

3. **物料编码在课程原始文件中不存在**。
   课程只给出物料**名称**与**数量关系**，没有编码。
   因此 `course_chair_case.json` 中的 `material_code` 是**系统自定义的编号方案**，
   名称与数量关系则严格来自课程原始文件，未作任何猜测与改动。

4. 转椅 BOM 只是**默认初始化案例**，不是硬编码。
   物料、BOM、数量、提前期、版本均可在系统中自由新增/修改/启停；
   本目录的数据用于“课程数据导入”，导入后即成为普通业务数据。
